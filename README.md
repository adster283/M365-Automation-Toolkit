# M365 Automation Toolkit

A collection of practical scripts, diagnostic collectors, and quick-reference guides for common Microsoft 365 and Windows support tasks.

The toolkit is designed to help MSP support staff troubleshoot issues, collect consistent diagnostic information, and complete common administration tasks quickly.

## Tool Directory

### Device and Troubleshooting Tools

| Tool                                                                       | Description                                                                                                         |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| [Collect All Device Logs](User-Device-Scripts/Collect-All-Device-Logs)     | Collects crash, Intune, application, event, and system logs when the issue is unclear or covers multiple areas.     |
| [Collect Device Crash Logs](User-Device-Scripts/Collect-Device-Crash-Logs) | Collects Windows crash dumps, event logs, power information, drivers, and system details.                           |
| [Collect Intune App Logs](User-Device-Scripts/Collect-Intune-App-Logs)     | Collects Intune and application deployment logs for failed installs, detection issues, and unexpected app removals. |
| [Reset Outlook](User-Device-Scripts/Reset-Outlook)                         | Clears local Outlook cache and profile data to troubleshoot persistent client-side Outlook issues.                  |
| [Reset Teams](User-Device-Scripts/Reset-Teams)                             | Clears local Microsoft Teams cache to resolve loading, sign-in, syncing, and stale-data issues.                     |

### Admin Task Cheat Sheets

| Guide                                                                            | Description                                                                                         |
| -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| [Calendar Access](Admin-Task-Cheatsheets/Calendar-Access.md)                     | Exchange Online commands for checking, adding, changing, and removing mailbox calendar permissions. |
| [Mailbox Auto Reply](Admin-Task-Cheatsheets/Mailbox-AutoReply.md)                | Commands for checking and configuring automatic replies on a mailbox.                               |
| [Shared Mailbox Sent Items](Admin-Task-Cheatsheets/Shared-Mailbox-Sent-Items.md) | Commands to ensure messages sent from a shared mailbox are saved in its Sent Items folder.          |

## Usage

Open the relevant tool or guide and follow the instructions provided.

Review the documentation before running a script. Some tools require local administrator rights and may collect sensitive diagnostic information that should only be uploaded to approved support locations.
